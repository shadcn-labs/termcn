## Usage

```tsx
import { GitStatus } from "@/components/ui/git-status";
```

```tsx
<GitStatus branch="main" staged={2} modified={5} ahead={1} behind={0} />
```

## API Reference

### GitStatus

| Prop       | Type     | Default    |
| ---------- | -------- | ---------- |
| `branch`   | `string` | `required` |
| `staged`   | `number` | `0`        |
| `modified` | `number` | `0`        |
| `ahead`    | `number` | `0`        |
| `behind`   | `number` | `0`        |
