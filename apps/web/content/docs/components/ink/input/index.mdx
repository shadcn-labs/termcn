<ComponentsList category="input" />

Ink input components participate in the shared focus manager. Use `autoFocus`
for the initially active control, `id` when you need to focus a specific
control programmatically, and `isDisabled` to remove a control from the focus
order. Tab and Shift+Tab remain reserved for moving between focused controls.
