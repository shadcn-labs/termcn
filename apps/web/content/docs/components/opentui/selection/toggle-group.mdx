## Usage

```tsx
import { ToggleGroup, ToggleGroupItem } from "@/components/ui/toggle-group";
```

```tsx
<ToggleGroup defaultValue={["bold"]} multiple>
  <ToggleGroupItem autoFocus label="Bold" value="bold" />
  <ToggleGroupItem label="Italic" value="italic" />
</ToggleGroup>
```

Horizontal groups use Left/Right and vertical groups use Up/Down. Home and End
move to the first or last enabled item.
