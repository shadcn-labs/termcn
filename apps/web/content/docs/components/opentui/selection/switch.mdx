## Usage

```tsx
import { Switch } from "@/components/ui/switch";
```

```tsx
<Switch
  defaultChecked
  label="Desktop notifications"
  onCheckedChange={setEnabled}
/>
```

`checked` makes the component controlled; `defaultChecked` initializes
uncontrolled state. `onChange` remains available as a compatibility alias for
`onCheckedChange`.

## API Reference

| Prop              | Type                                                | Default   |
| ----------------- | --------------------------------------------------- | --------- |
| `label`           | `string`                                            | required  |
| `checked`         | `boolean`                                           | -         |
| `defaultChecked`  | `boolean`                                           | `false`   |
| `onCheckedChange` | `(checked: boolean, details: PressDetails) => void` | -         |
| `disabled`        | `boolean`                                           | `false`   |
| `symbols`         | `"round" \| "ascii"`                                | `"round"` |
| `width`           | `3 \| 5`                                            | `3`       |
| `autoFocus`       | `boolean`                                           | `false`   |
