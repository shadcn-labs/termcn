## Usage

```tsx
import {
  Collapsible,
  CollapsibleContent,
  CollapsibleTrigger,
} from "@/components/ui/collapsible";
```

```tsx
<Collapsible defaultOpen>
  <CollapsibleTrigger autoFocus label="Build details" />
  <CollapsibleContent>
    <text>12 tasks completed.</text>
  </CollapsibleContent>
</Collapsible>
```

Use `open` with `onOpenChange` for controlled state. `keepMounted` retains the
content renderable while closed and hides it with OpenTUI's `display` property.

## API Reference

| Part                 | Key props                                                  |
| -------------------- | ---------------------------------------------------------- |
| `Collapsible`        | `open`, `defaultOpen`, `onOpenChange`, `disabled`          |
| `CollapsibleTrigger` | `label`, `openMark`, `closedMark`, `autoFocus`, `isActive` |
| `CollapsibleContent` | `children`, `keepMounted`, `paddingLeft`                   |
