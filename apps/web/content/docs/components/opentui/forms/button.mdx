## Usage

```tsx
import { Button } from "@/components/ui/button";
```

```tsx
<Button
  autoFocus
  label="Deploy"
  onPress={({ source }) => console.log(source)}
/>
```

Button activates on unmodified Enter, Return, or Space and on a primary
pointer press that starts and ends on the control. `autoFocus` is useful for a
single primary action; otherwise focus it from your application or by pointer.

## API Reference

| Prop        | Type                                     | Default     |
| ----------- | ---------------------------------------- | ----------- |
| `children`  | `ReactNode`                              | -           |
| `label`     | `string` (used when children are absent) | -           |
| `onPress`   | `(details: PressDetails) => void`        | -           |
| `intent`    | `"neutral" \| "primary" \| "danger"`     | `"primary"` |
| `size`      | `"compact" \| "comfortable"`             | `"compact"` |
| `disabled`  | `boolean`                                | `false`     |
| `autoFocus` | `boolean`                                | `false`     |
| `isActive`  | `boolean`                                | `true`      |
