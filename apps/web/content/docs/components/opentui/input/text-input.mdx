## Usage

```tsx
import { TextInput } from "@/components/ui/text-input";
```

```tsx
<TextInput
  autoFocus
  label="Project Name"
  placeholder="my-project"
  onSubmit={(value) => console.log("Name:", value)}
/>
```

### Cursor and editing

With `showCursor` (default `true`), use Left, Right, Home, and End to move
the insertion point. Backspace removes before the cursor, Delete removes after
it, and terminal paste inserts at the current cursor position.

## API Reference

### TextInput

| Prop                  | Type                                            | Default     |
| --------------------- | ----------------------------------------------- | ----------- |
| `value`               | `string`                                        | -           |
| `defaultValue`        | `string`                                        | `""`        |
| `onValueChange`       | `(value: string) => void`                       | -           |
| `onChange`            | `(value: string) => void` (compatibility alias) | -           |
| `onSubmit`            | `(value: string) => void`                       | -           |
| `placeholder`         | `string`                                        | `""`        |
| `mask`                | `string`                                        | -           |
| `showCursor`          | `boolean`                                       | `true`      |
| `highlightPastedText` | `boolean`                                       | `false`     |
| `validate`            | `(value: string) => string\|null`               | -           |
| `width`               | `number`                                        | `40`        |
| `label`               | `string`                                        | -           |
| `autoFocus`           | `boolean`                                       | `false`     |
| `disabled`            | `boolean`                                       | `false`     |
| `readOnly`            | `boolean`                                       | `false`     |
| `isActive`            | `boolean`                                       | `true`      |
| `id`                  | `string`                                        | -           |
| `bordered`            | `boolean`                                       | `true`      |
| `borderStyle`         | `"single" \| "double" \| "rounded" \| "heavy"`  | `"rounded"` |
| `paddingX`            | `number`                                        | `1`         |
| `cursor`              | `string`                                        | `"█"`       |
