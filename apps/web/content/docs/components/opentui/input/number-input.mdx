## Usage

```tsx
import { NumberInput } from "@/components/ui/number-input";
```

```tsx
<NumberInput
  autoFocus
  label="Quantity"
  min={0}
  max={100}
  step={1}
  onChange={(value) => console.log("Value:", value)}
/>
```

Arrow Up and Down use `step`, Option+Arrow uses `smallStep`, and Shift+Arrow
or Page Up/Down uses `largeStep`. Home and End jump to finite bounds. Drafts
such as `-` remain editable and are repaired or clamped on Enter or blur.

## API Reference

### NumberInput

| Prop            | Type                                                                 | Default                  |
| --------------- | -------------------------------------------------------------------- | ------------------------ |
| `value`         | `number \| null`                                                     | -                        |
| `defaultValue`  | `number \| null`                                                     | `null`                   |
| `onValueChange` | `(value: number \| null, details: NumberInputChangeDetails) => void` | -                        |
| `onValueCommit` | `(value: number \| null, details: NumberInputChangeDetails) => void` | -                        |
| `onChange`      | `(value: number) => void`                                            | -                        |
| `onSubmit`      | `(value: number) => void`                                            | -                        |
| `min`           | `number`                                                             | -                        |
| `max`           | `number`                                                             | -                        |
| `step`          | `number`                                                             | `1`                      |
| `smallStep`     | `number`                                                             | `0.1`                    |
| `largeStep`     | `number`                                                             | `10`                     |
| `placeholder`   | `string`                                                             | `""`                     |
| `label`         | `string`                                                             | -                        |
| `id`            | `string`                                                             | -                        |
| `autoFocus`     | `boolean`                                                            | `false`                  |
| `disabled`      | `boolean`                                                            | `false`                  |
| `readOnly`      | `boolean`                                                            | `false`                  |
| `isActive`      | `boolean`                                                            | `true`                   |
| `format`        | `(n: number) => string`                                              | -                        |
| `borderStyle`   | `"single" \| "double" \| "rounded" \| "heavy"`                       | `"rounded"`              |
| `paddingX`      | `number`                                                             | `1`                      |
| `cursor`        | `string`                                                             | `"█"`                    |
| `stepHint`      | `string`                                                             | `"↑ +{step}  ↓ -{step}"` |
