## Usage

```tsx
import { TextArea } from "@/components/ui/text-area";
```

```tsx
<TextArea
  autoFocus
  label="Description"
  placeholder="Enter a description..."
  rows={4}
  onSubmit={(value) => console.log("Submitted:", value)}
/>
```

`rows` controls the visible viewport, not the document length. Use Ctrl+Enter
to submit while Enter inserts a new line.

## API Reference

| Prop            | Type                                            | Default     |
| --------------- | ----------------------------------------------- | ----------- |

| `defaultValue`  | `string`                                        | `""`        |
