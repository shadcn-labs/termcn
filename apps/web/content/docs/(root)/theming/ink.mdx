**Theming** in termcn means choosing a terminal theme with tokens for colors, borders, and spacing. Ink theme-aware components work without a provider. Mount `ThemeProvider` only when an application needs to override the default theme.

Theme packages install into `lib/terminal-themes/`, hooks install into `hooks/`, and providers install into `providers/`.

## ThemeProvider

Install the provider when you want to customize the active theme:

```bash
npx shadcn@latest add @termcn/ink/theme-provider
```

### Usage

```tsx
import { ThemeProvider } from "@/providers/theme-provider";
import { Spinner } from "@/components/ui/spinner";
import { defaultTheme } from "@/lib/terminal-themes/default";

export function Example() {
  return (
    <ThemeProvider theme={defaultTheme}>
      <Spinner label="Generating registry items" />
    </ThemeProvider>
  );
}
```

Components receive `use-theme`, `use-unicode`, and `use-motion` transitively as `registry:hook` items when needed. Import the hooks directly from the configured shadcn hooks alias:

```tsx
import { useTheme, useThemeUpdater } from "@/hooks/use-theme";
import { useUnicode } from "@/hooks/use-unicode";
import { useMotion } from "@/hooks/use-motion";
```

Each hook has a usable default context, so these imports do not require a mounted provider.

## MotionProvider and UnicodeProvider

Motion and Unicode settings are independent from the active theme. Install only the provider that your application needs:

```bash
npx shadcn@latest add @termcn/ink/motion-provider @termcn/ink/unicode-provider
```

The providers can be composed in any order because each owns only its matching context:

```tsx
import { MotionProvider } from "@/providers/motion-provider";
import { ThemeProvider } from "@/providers/theme-provider";
import { UnicodeProvider } from "@/providers/unicode-provider";
import { defaultTheme } from "@/lib/terminal-themes/default";

export function Example() {
  return (
    <ThemeProvider theme={defaultTheme}>
      <MotionProvider reducedMotion>
        <UnicodeProvider unicode={false}>
          <App />
        </UnicodeProvider>
      </MotionProvider>
    </ThemeProvider>
  );
}
```

Without these providers, motion follows `NO_MOTION=1` and `CI=true`, while Unicode follows terminal detection and `NO_UNICODE=1`.

## Custom themes

```tsx
import { createTheme } from "@/providers/theme-provider";

export const oceanTheme = createTheme({
  name: "ocean",
  colors: {
    primary: "#0ea5e9",
    accent: "#22d3ee",
    background: "#0f172a",
    foreground: "#e2e8f0",
  },
});
```
