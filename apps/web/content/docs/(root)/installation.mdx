## Prerequisites

Node.js 20.18 or later. OpenTUI projects also use Bun at runtime.

## Initialize a project

Run the interactive initializer:

```bash
npx termcn@latest init
```

You can also select everything up front:

```bash
npx termcn@latest init --framework ink --theme dracula --font jetbrains-mono --icons codicons --template app-shell --name my-terminal-app --yes
```

This writes `components.json`, installs the selected theme and template, and
creates a runnable entry point plus typed Nerd Font helpers when the target
directory is empty. You can build the same command visually on the
[Create page](/create).

Your terminal emulator controls the actual terminal font. After initialization,
install the selected Nerd Font Mono variant and choose it in your terminal
profile. See [Fonts and icons](/docs/nerd-fonts) for the supported families,
generated files, and usage.

## Add a component

After initialization, component names resolve through the framework stored in
`components.json`:

```bash
npx termcn@latest add spinner
```

## Usage

Import and use the component:

```tsx
import { Spinner } from "@/components/ui/spinner";
import { Text } from "ink";

export function App() {
  return (
    <>
      <Text>Loading...</Text>
      <Spinner />
    </>
  );
}
```

## Install a Theme

termcn ships bundled terminal themes that integrate with the `ThemeProvider`:

For Ink:

```bash
npx termcn@latest add theme-dracula
```

For OpenTUI:

```bash
npx termcn@latest add theme-dracula
```

Then wrap your app:

```tsx
import { ThemeProvider } from "@/components/ui/theme-provider";
import { draculaTheme } from "@/lib/terminal-themes/dracula";

export function App() {
  return (
    <ThemeProvider theme={draculaTheme}>
      {/* your Ink or OpenTUI tree */}
    </ThemeProvider>
  );
}
```
