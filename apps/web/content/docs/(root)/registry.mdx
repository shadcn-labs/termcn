title: Registry
description: Learn how to use the termcn registry with the termcn CLI.

The **termcn** registry ships Ink and OpenTUI terminal UI components and themes in a [shadcn-compatible registry format](https://ui.shadcn.com/docs/registry). The `termcn init` command writes the registry and framework settings to `components.json`, then `termcn add` resolves plain item names against that framework.

## Setup

Run `npx termcn@latest init`, or add the registry manually:

```json
{
  "registries": {
    "@termcn": "https://termcn.dev/r/{style}/{name}.json"
  }
}
```

Set `style` to `ink` or `opentui`. You can replace `@termcn` with another namespace; it only needs to match what you pass to `termcn add`.

## Usage

After initialization, plain item names use the framework stored in `components.json`.

Install an Ink component:

```bash
npx termcn@latest add spinner
```

Install an OpenTUI component:

```bash
npx termcn@latest add spinner
```

Install a theme for the matching base:

```bash
npx termcn@latest add theme-dracula
```

```bash
npx termcn@latest add theme-dracula
```

Install the theme provider for each base:

```bash
npx termcn@latest add theme-provider
```

```bash
npx termcn@latest add theme-provider
```

Without a registry alias, use the full URL (as on each docs page):

```bash
npx termcn@latest add https://termcn.dev/r/ink/spinner.json
```

```bash
npx termcn@latest add https://termcn.dev/r/opentui/spinner.json
```
