[MCP](https://modelcontextprotocol.io/) is an open protocol that standardizes how applications provide context to LLMs. The termcn CLI can register an MCP server so your editor can discover registry components—including the Ink and OpenTUI items you install through termcn.

## Configure MCP

Run:

```bash
npx termcn@latest mcp init
```

Choose your MCP client when prompted, then enable the MCP server in that client to finish setup.

## Usage

With MCP enabled, you can ask your IDE to work with **Ink** and **OpenTUI** terminal UI patterns and termcn registry components. Example prompts:

- Build a CLI status screen with **Spinner**, **ProgressBar**, and **StatusMessage**.
- Add a **CommandPalette** and **Menu** for keyboard-driven navigation in a terminal app.
- Create an AI-style flow with **ChatThread**, **ChatMessage**, **ToolCall**, and **StreamingText**.
- Lay out a TUI dashboard using **Box**, **Stack**, **Table**, and **DataGrid** with a **Sidebar**.
- Implement a multi-step flow with **Wizard**, **Form**, **Confirm**, and **Modal**.

Install components from this registry with `npx termcn@latest add`, then reference them in your Ink or OpenTUI `ThemeProvider` tree as usual.
