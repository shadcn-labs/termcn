## Recursos

- 🎨 **Compatível com temas** — Adapta-se automaticamente ao tema de terminal escolhido
- 🎯 **Zero configuração** — Funciona imediatamente com padrões sensatos
- 📦 **Compatível com shadcn/ui** — Usa o mesmo formato de registro e a mesma CLI
- ⌨️ **Impulsionado por Ink e OpenTUI** — Acesso total a uma renderização de terminal poderosa
- 🧩 **Composável** — Crie UIs de terminal complexas com componentes simples e declarativos
- 📊 **Gráficos e dados** — Gráficos de barras, gráficos de linhas, medidores, mapas de calor e muito mais
- 🤖 **Componentes de IA** — Mensagens de chat, aprovações de ferramentas, texto em streaming e blocos de raciocínio
- 🎮 **Navegação** — Paletas de comandos, abas, menus, barras laterais e paginação
