## Características

- 🎨 **Compatible con temas** — Se adapta automáticamente al tema de terminal que elijas
- 🎯 **Sin configuración** — Funciona de inmediato con valores predeterminados razonables
- 📦 **Compatible con shadcn/ui** — Usa el mismo formato de registro y la misma CLI
- ⌨️ **Impulsado por Ink y OpenTUI** — Acceso completo a un potente renderizado en terminal
- 🧩 **Componible** — Construye interfaces de terminal complejas con componentes simples y declarativos
- 📊 **Gráficos y datos** — Gráficos de barras, gráficos de líneas, medidores, mapas de calor y más
- 🤖 **Componentes de IA** — Mensajes de chat, aprobaciones de herramientas, texto en streaming y bloques de razonamiento
- 🎮 **Navegación** — Paletas de comandos, pestañas, menús, barras laterales y paginación
