## 特徴

- 🎨 **テーマ対応** — 選択したターミナルテーマに自動で適応
- 🎯 **ゼロコンフィグ** — 妥当なデフォルト値ですぐに使える
- 📦 **shadcn/ui 互換** — 同じレジストリ形式と CLI を使用
- ⌨️ **Ink と OpenTUI による駆動** — 強力なターミナルレンダリングをフルに活用
- 🧩 **コンポーザブル** — シンプルで宣言的なコンポーネントから複雑なターミナル UI を構築
- 📊 **チャートとデータ** — 棒グラフ、折れ線グラフ、ゲージ、ヒートマップなど
- 🤖 **AI コンポーネント** — チャットメッセージ、ツール承認、ストリーミングテキスト、思考ブロック
- 🎮 **ナビゲーション** — コマンドパレット、タブ、メニュー、サイドバー、ページネーション
