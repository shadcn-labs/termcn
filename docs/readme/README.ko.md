## 특징

- 🎨 **테마 인식** — 선택한 터미널 테마에 자동으로 적응
- 🎯 **제로 설정** — 합리적인 기본값으로 바로 사용 가능
- 📦 **shadcn/ui 호환** — 동일한 레지스트리 형식과 CLI 사용
- ⌨️ **Ink와 OpenTUI 기반** — 강력한 터미널 렌더링에 완전히 접근
- 🧩 **조합 가능** — 간단하고 선언적인 컴포넌트로 복잡한 터미널 UI 구성
- 📊 **차트와 데이터** — 막대 차트, 선 차트, 게이지, 히트맵 등
- 🤖 **AI 컴포넌트** — 채팅 메시지, 도구 승인, 스트리밍 텍스트, 사고 블록
- 🎮 **내비게이션** — 커맨드 팔레트, 탭, 메뉴, 사이드바, 페이지네이션

## 커뮤니티

termcn 커뮤니티는 [GitHub](https://github.com/shadcn-labs/termcn)에 있으며, 질문하고 아이디어를 공유하고 만든 것을 보여줄 수 있습니다.

## 기여하기

기여를 환영합니다. 저장소를 로컬에서 실행하고 변경 사항을 반영하는 방법은 [CONTRIBUTING.md](../../CONTRIBUTING.md)를 참고하세요. 협업에는 [issues](https://github.com/shadcn-labs/termcn/issues)와 [discussions](https://github.com/shadcn-labs/termcn/discussions)를 사용하세요. 참여함으로써 [행동 강령](../../CODE_OF_CONDUCT.md)에 동의하는 것으로 간주됩니다.

## 보안
